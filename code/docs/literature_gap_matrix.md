# 参考文献证据矩阵与创新边界

## 1. 逐篇证据矩阵

| 文献 | 问题与状态空间 | 核心方法 | 已有保证或证据 | 对本项目的直接限制 |
|---|---|---|---|---|
| Isaacs and Hespanha, 2013 | 平面 Dubins 车辆访问多个邻域，状态为 SE(2) | 邻域采样，含交叠节点集的 GTSP，再经 Noon-Bean 变换为 ATSP | 对相同样本，所得路线不劣于对照方法；有数值和 UAV 外场演示 | “服务区域采样 + GTSP”已经存在，不能单独作为创新；原文未处理服务成功概率、地图不确定性和昂贵边代价的按需精算 |
| Ishida et al., 2019 | 在二维代价地图上按给定顺序访问凸目标区域 | Multi-Region A* 与窗口化近似版本 | 完整版本最优；窗口版本在规划时间与最优性间折中 | 目标顺序固定，未联合求解区域内状态选择与访问顺序，也没有非完整运动学或概率服务约束 |
| Nedjatia and Vizvári, 2020 | 访问不同半径圆邻域的连续 TSPN | 非线性模型、线性化和两阶段求解 | 小中规模数值验证 | 说明连续邻域路由已有精确建模；未处理障碍、非对称运动代价、动态环境和不确定性 |
| Suárez-Ruiz et al., 2018 | 多目标、多逆解的机器人任务排序 | 先在任务空间求序，再在分层图中选配置，最后做碰撞运动规划 | 245 个目标上以更少时间获得与 GTSP 相近质量 | “代理代价减少运动规划查询”已有强基线；该方法没有对代理与真实代价差异给出全局上下界证书 |
| Chandak et al., 2023 | 连续高维空间中的多目标路径寻找 | IST* 交替执行知情采样、MST 更新和基于上下界的安全剪枝 | 证明采样图上的 MST 正确，渐近 2-近似；实验显示优于均匀采样 | “上下界 + 安全剪枝 + 少算边”本身不是新颖点。本项目必须突出概率服务区域、每组状态选择、非对称 SE(2) 代价与有限候选最优性间隙 |
| Sandakalum and Ang, 2022 | 移动机械臂运动规划系统综述 | 对采样、优化、搜索及联合/分离规划分类 | 指出底盘与机械臂分离规划次优，真实不确定性仍是开放问题 | 为概率服务区域和底盘-操作能力联合表示提供动机，但综述本身不构成算法基线 |
| Sun et al., 2023 | 动态环境下单机器人局部避障 | 模糊权重 DWA，并用全局路径子目标引导 | 报告规划时间和路径长度改善 | 属于执行层局部规划；不能证明多目标任务层联合优化或全局最优性 |
| Xiang et al., 2022 | 静态仓库中的多点访问 | 改进 A*、节点删减与贪心排序 | 五目标仿真中报告约 5% 路径改善 | 点目标、弱基线、无不确定性和理论保证，适合作为应用型对照而非新颖性锚点 |
| Yang et al., 2024 | 农业多区域任务的路径与调度 | 全部任务对之间运行改进 A* 构造非对称代价矩阵，再用精英遗传算法排序 | 静态、多场景仿真与消融 | “非对称代价矩阵 + 排序”已经存在；其完整矩阵需要大量规划查询，且没有可证界或风险校准，正是本项目可攻击的缺口 |
| Yin et al., 2024 | 单目标全局路径与局部轨迹执行 | 改进 RRT* 与 TEB 融合 | 仿真和实体平台验证路径长度、转折点与运动学可行性 | 只解决执行层单目标规划，可用作底层 oracle，不应包装成任务层科研创新 |

## 2. 不能再声称的新颖点

1. 不能把“把目标表示成一个区域”作为新颖点，TSPN、DTSPN 和 Multi-Region A* 已充分覆盖。
2. 不能把“用 GTSP 同时选择候选和顺序”作为新颖点，Isaacs 及 RoboTSP 已给出典型路线。
3. 不能把“先全局后局部”或“A*/RRT* 与 TEB/DWA 融合”作为主要贡献。
4. 不能把“上下界剪枝减少运动规划计算”单独作为新颖点，IST* 已有相近思想与理论保证。
5. 不能只比较路径长度；必须比较风险校准误差、精确边查询数、证书间隙和真实服务成功率。

## 3. 可成立的论文问题

建议把主问题冻结为：

> 在目标与机器人状态存在不确定性、服务位置不是单点、候选间真实非对称运动代价只能通过昂贵规划查询获得时，如何联合选择每个目标的可服务底盘状态和访问顺序，并在给定计算预算内返回风险已校准、可执行且带有全局质量证书的路线？

其差异化由四个缺一不可的要素组成：

- 机会约束定义的概率服务区域，而不是确定性圆邻域；
- 每个目标组中选择一个 SE(2) 服务状态，而不是访问固定点；
- 非对称、昂贵且最初未知的真实运动代价；
- 有限候选问题上的 `LB <= J* <= UB` 与随时相对间隙，而不是仅报告启发式结果。

## 4. 首轮可证伪假设

- H1：在相同名义服务范围下，概率服务区域的留出集失败率不超过风险预算上限，并显著低于确定性区域。
- H2：在零容许间隙下，带界惰性求解与完整代价矩阵得到相同最优目标值，同时减少精确运动规划查询。
- H3：在非零时间预算下，算法返回的经验次优率不超过其报告的相对间隙。

## 5. 最低实验包

1. 小规模实例：与完整精算动态规划或 MILP 的最优解逐例核对。
2. 中等规模实例：比较完整矩阵、无证书惰性方法、IST* 风格剪枝适配版和本文方法。
3. 风险实验：改变定位误差、目标误差、风险预算和校准样本数，报告可靠性图与置信区间。
4. 代价实验：改变候选数、障碍密度和目标数，报告精确边比例、运行时间、LB/UB 间隙与路线质量。
5. 系统实验：将代理 oracle 替换为 Hybrid A* 或 OMPL，最后再接入 TEB/DWA 与真实机器人。

## 6. 当前最大审稿风险

- 与 IST* 的关系必须在引言和相关工作中正面说明，并以“组选择、非对称性、机会约束、有限候选证书”给出形式化差异。
- 概率服务区域若只做蒙特卡洛过滤而没有独立校准或有限样本保证，会被认为是工程调参。
- 若精确代价仍是人工代理函数，所有结果只能叫预实验，不能写入论文主结论。
- 若完整矩阵基线规模太小、无真实规划查询计时，无法证明惰性求解的必要性。
