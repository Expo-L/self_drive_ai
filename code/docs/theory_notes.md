# 概率服务区域与带界惰性路由：理论工作稿

本文档只记录已经与当前实现一致的数学性质，以及正式论文仍需补足的证明。预实验数值不是论文结论。

## 1. 有限候选问题

设任务集合为 `I={1,...,m}`。任务 `i` 的离散服务候选集合为 `G_i={s_i^1,...,s_i^{K_i}}`，候选状态属于 SE(2)。每条有向边 `e=(a,b)` 具有真实运动代价 `c_e`；若不可达，则 `c_e=+∞`。代价可以不对称。

一个可行解需要：

1. 从每个 `G_i` 中恰好选择一个状态；
2. 给出所有任务的访问排列；
3. 所有连续访问边均可达。

开放路线的目标是最小化起点到首个服务状态以及相邻服务状态之间的总代价。当前代码使用子集动态规划精确求解有限候选问题，复杂度为 `O(2^m m^2 K^2)`，其中 `K=max_i K_i`；内存复杂度为 `O(2^m mK)`。这只适合小中规模最优值核对，不是最终的大规模求解器。

## 2. 部分精算图

对每条边给定可快速计算的下界 `l_e`，要求 `0 <= l_e <= c_e`。设已经调用昂贵运动规划器精算的边集合为 `E_q`。部分精算代价定义为：

`w_e = c_e`，当 `e in E_q`；否则 `w_e = l_e`。

用 `w_e` 求得的有限候选最优值记为 `LB(E_q)`。

### 命题 1：部分精算最优值是有效下界

对任何可行路线 `r`，逐边有 `w_e <= c_e`，所以 `sum_{e in r} w_e <= sum_{e in r} c_e`。对所有路线取最小值得：

`LB(E_q) <= J*`。

该结论不要求边代价对称，也不要求三角不等式；只依赖逐边下界可采纳。

### 命题 2：完整精算可行路线给出有效上界

若路线 `r` 上每条边均已精算且有限，则其真实代价 `J(r)` 满足：

`J* <= J(r)=UB`。

因此任意时刻都有 `LB <= J* <= UB`。

### 定理 1：停止时的相对最优性证书

算法在满足

`UB-LB <= eta * UB`, `0 <= eta < 1`

时停止，则返回路线满足：

`0 <= (UB-J*)/UB <= (UB-LB)/UB <= eta`。

这里的误差是相对于当前可行解上界定义的。代码已直接按该不等式停止并报告 `(UB-LB)/UB`。

### 定理 2：零间隙模式有限终止

假设候选和有向边集合有限、精确 oracle 确定且至少存在一条可行路线。每个未终止迭代至少精算当前乐观最优路线上的一条新边。由于边数有限，算法最终会遇到一条所有边均已精算的乐观最优路线，或把所有相关边精算完。此时 `LB=UB=J*`，零间隙模式有限终止。

正式论文还需要把“相关边”的定义与不可达边处理写成严格伪代码，并证明无可行路线时的终止行为。

### 命题 3：有向分组强制边筛选是安全的

对任意有向边 `e`，定义强制该边出现时的部分精算路线下界：

`LB_e = min_{r: e in r} sum_{a in r} w_a`。

因为逐边有 `w_a <= c_a`，任何包含 `e` 的真实路线代价均不小于 `LB_e`。若当前存在已完全精算的可行路线上界 `UB`，且 `LB_e >= UB`，则任何包含 `e` 的路线都不可能严格改善当前解。由于当前可行路线的边已精算且不会被列入未查询筛选集，删除 `e` 仍保留代价为 `UB` 的可行解，因此不改变最优值或最优性证书。

当前实现用前向子集 DP 与后缀子集 DP 一次构造所有 `LB_e`，适用于非对称代价和每组恰选一个候选的情形。查询选择再优先选取“临时排除后全局下界最高”的乐观路线边。后一步只是启发式查询顺序，不影响筛选安全性与最终证书。

该筛选每轮增加组合 DP 开销，因而不应默认替换路线惰性基线。探索实验显示，在便宜代理 oracle 上平均仅多减少 0.81% 查询却增加约 6.6 倍运行时间；在一个连续曲率 Hybrid A* 实例上，查询从 61 降至 48，运行时间从 13.75 s 降至 11.45 s。因此它的暂定适用条件是单次精确运动规划远比子集 DP 昂贵；该条件尚需多地图证据。

## 3. 当前下界的适用范围

当前 Lattice A* 与 Hybrid A* 原型使用量化端点之间的欧氏距离作为 `l_e`。精确代价由非负的运动弧长、倒车惩罚、转向惩罚和终点残差组成，因此实验代码中有 `l_e <= c_e`。

正式系统若把时间、能耗或风险加入目标函数，不能直接继续使用纯欧氏下界。必须分别给出：

- 时间下界，例如欧氏距离除以最大线速度；
- 能耗下界，例如单位距离最低能耗乘欧氏距离；
- 服务切换下界，仅当该项对所有可行边均不可避免时才能加入；
- 学习预测、拥挤度评分和经验惩罚只能用于查询排序，除非能够证明它们不高估真实代价。

## 4. 概率服务区域

对固定候选 `s`，设一次执行成功事件为 Bernoulli 随机变量，真实成功概率为 `p_s`。在独立校准集上观察 `n` 次执行和 `k` 次成功，计算单侧 Clopper-Pearson 下界 `L_CP(k,n,delta)`。候选接受规则为：

`L_CP(k,n,delta) >= 1-epsilon`。

对事先固定的单个候选，Clopper-Pearson 构造保证下界的覆盖概率不低于 `1-delta`。因此，满足接受规则的候选可以获得候选级的有限样本风险声明。

### 多候选选择风险

候选级 95% 置信下界不是所有候选同时成立的族级保证。当前代码已增加 Bonferroni 族级版本：对候选族大小 `K`，把每候选失覆盖概率设为 `delta/K`，即使用置信水平 `1-delta/K`。由并集界，在模型与独立抽样假设下，整个候选族中至少一个下界失败的概率不超过 `delta`。

正式论文还可比较下列方案：

1. 用 Bonferroni 或其他同时推断方法，把每候选显著性水平设为 `delta/K`；
2. 先用训练样本生成和排序候选，再只对最终保留候选使用独立校准集；
3. 使用适合选择后推断或保形风险控制的统一校准方法。

即使完成了 Bonferroni 同时覆盖，也只能对校准模型中的候选置信界作族级声明，不能据此声称整条任务路线在模型失配下具有 `1-delta` 的实机联合可靠性。

## 5. 与最接近工作的形式化差异

Chandak 等人的 IST* 对固定终端的连续多目标路径问题维护终端间上下界，利用最小生成树环性质安全剪枝，并给出渐近 2-近似。当前问题与其重叠在“昂贵运动代价、上下界和按需精算”，因此不能把这些要素单独声称为新颖。

IST* 的剪枝条件来自无向固定终端图的 MST 环性质。将该规则直接用于有向分组路由会失去理论前提。命题 3 的强制边条件不依赖对称性、三角不等式或 MST，但这个差异只能作为形式化贡献候选，必须经过强基线和多实例效率验证后才能进入论文主张。

需要形式化证明的差异是：

- 终端不是固定点，而是通过机会约束获得的服务状态组；
- 优化同时决定每组状态与访问顺序；
- 边是有向且可能不可达，MST 环性质不能直接使用；
- 当前证书针对离散后的有限候选最优值，而不是对连续问题声称全局最优；
- 风险校准误差和离散化误差需要与路由最优性间隙分开报告。

## 6. 已验证、待验证和禁止表述

### 当前可以表述

- 在所测有限实例上，零间隙惰性求解与完整矩阵得到相同目标值。
- 当前实现始终维护逐边可采纳下界，并可报告有限候选问题的上下界。
- 合成风险扫描中，候选级 Clopper-Pearson 过滤比名义几何范围更保守。

### 仍待验证

- 连续曲率 Hybrid A* 查询减少在多地图、多目标数和多候选数下是否稳定。
- Bonferroni 以外的同时或选择后风险控制是否能以更少保守性保持覆盖。
- 真实机器人上的服务成功率、在线重规划延迟和能耗收益。

### 当前禁止表述

- “首次提出上下界惰性多目标规划”。
- “证明连续概率服务区域问题全局最优”。
- “保证整条路线的服务成功概率不低于 1-epsilon”。
- “显著优于现有方法”，除非完成预注册的统计比较。
